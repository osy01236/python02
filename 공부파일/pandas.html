Pandas 데이터 분석 정리

Pandas는 표 형태의 데이터를 읽고, 조건으로 찾고, 정렬하고, 그룹별로 집계하는 도구입니다. 엑셀 표를 코드로 다룬다고 생각하면 이해하기 쉽습니다.

1. DataFrame 이해

DataFrame은 행과 열을 가진 표입니다. 학생 이름, 점수, 성별처럼 서로 관련된 데이터를 한 번에 다룰 수 있습니다.

import pandas as pd

df = pd.DataFrame({
    "name": ["이순신", "박문수", "홍길동"],
    "score": [89, 67, 95],
    "gender": ["남", "남", "남"]
})

print(df)
print(df["score"].sum())

열 하나를 선택하면 Series, 여러 열과 행을 가진 표는 DataFrame입니다.

2. 데이터 확인 습관

파일을 읽은 뒤 바로 분석하지 말고, 데이터가 어떻게 생겼는지 먼저 확인해야 합니다.

코드언제 쓰나
df.head()앞부분 몇 줄 확인
df.tail()마지막 몇 줄 확인
df.info()열 이름, 결측치, 타입 확인
df.describe()숫자 열의 평균, 최솟값, 최댓값 확인
 
df = pd.read_csv("pandas_fruit.csv")

print(df.head(3))
print(df.info())
print(df.describe())

3. 조건 필터링

분석에서 가장 많이 쓰는 부분입니다. “80점 이상”, “판매량 10개 이상”, “이름에 특정 글자가 포함” 같은 질문을 코드로 바꿉니다.

high_score = df[df["score"] >= 80]
range_score = df[(df["score"] >= 80) & (df["score"] <= 90)]
name_match = df[df["name"].str.contains("김")]
selected = df[df["name"].isin(["이순신", "홍길동"])]

조건이 여러 개일 때는 and 대신 &, or 대신 |를 쓰고 각 조건을 괄호로 감싸야 합니다.

4. 정렬과 value_counts

데이터를 높은 순서, 낮은 순서로 정렬하거나 특정 값이 몇 번 나왔는지 셀 수 있습니다.

print(df.sort_values("score", ascending=False))
print(df.sort_values(by=["fruit", "sale"], ascending=False))
print(df["fruit"].value_counts())

ascending=False는 내림차순입니다. 점수 높은 학생, 가격 높은 상품을 찾을 때 사용합니다.

5. groupby로 묶어서 계산

카테고리별 합계, 과일별 평균 가격, 성별 평균 점수처럼 “그룹별 통계”를 구합니다.

sale_sum = df.groupby("fruit")["sale"].sum()
price_mean = df.groupby("fruit")["price"].mean().round(2)

summary = df.groupby("fruit").agg({
    "sale": ["sum", "mean"],
    "price": ["max", "min"]
})
집계 함수의미
sum합계
mean평균
count결측치를 제외한 개수
size결측치를 포함한 개수
max, min최댓값, 최솟값

6. 파일, SQL, JSON 데이터

이 폴더에서는 CSV뿐 아니라 SQL 결과와 JSON annotation 데이터도 DataFrame으로 바꾸는 흐름을 배웠습니다.

# CSV
df = pd.read_csv("pandas_fruit.csv")

# SQL
df = pd.read_sql("select * from item", engine)

# JSON annotation 일부를 DataFrame으로
df = pd.DataFrame(annotations)

현업 흐름은 보통 “파일/DB/API에서 데이터 가져오기 → DataFrame으로 정리 → 통계/시각화/보고서 생성”입니다.
