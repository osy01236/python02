OpenCV 이미지·영상 처리 정리

OpenCV는 이미지와 영상을 배열로 읽고, 색상 변환, 필터링, 경계 검출, contour, 움직임 감지 등을 처리하는 라이브러리입니다. AI가 찾은 결과를 화면에 표시할 때도 자주 사용합니다.

1. 이미지 읽기와 배열 감각

OpenCV로 읽은 이미지는 NumPy 배열입니다. 컬러 이미지는 보통 (높이, 너비, 3) 모양이고, OpenCV는 색상 순서를 RGB가 아니라 BGR로 다룹니다.

import cv2

img = cv2.imread("opencv/images/cat.png")

print(type(img))    # numpy.ndarray
print(img.shape)    # 높이, 너비, 채널

cv2.imshow("image", img)
cv2.waitKey(0)
cv2.destroyAllWindows()

OpenCV는 imshow 후에 waitKey를 호출해야 창이 유지됩니다.

2. ROI와 이미지 자르기

ROI는 Region Of Interest, 관심 영역입니다. 이미지에서 특정 부분만 잘라 분석할 때 사용합니다.

img = cv2.imread("opencv/images/cat.png")

roi = img[20:120, 130:230]
cv2.imshow("roi", roi)
cv2.waitKey(0)

배열 자르기는 img[y1:y2, x1:x2] 순서입니다. 좌표는 x, y로 말하지만 배열은 행, 열이라 y가 먼저 옵니다.

3. 전처리: 크기, 흑백, blur, threshold

이미지를 분석하기 전에 크기를 맞추고, 흑백으로 바꾸고, 노이즈를 줄이고, 흰색/검은색으로 분리합니다.

img = cv2.imread("opencv/images/dog.png")
resize_img = cv2.resize(img, (320, 240))
gray = cv2.cvtColor(resize_img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)

_, thresh = cv2.threshold(
    blur,
    140,
    255,
    cv2.THRESH_BINARY
)
처리목적
resize속도와 크기 통일
grayscale색상 정보를 줄이고 밝기만 사용
blur노이즈 감소
threshold객체와 배경 분리

4. Edge, contour, bounding box

경계선을 찾고, 연결된 영역을 contour로 묶고, 그 영역을 감싸는 사각형을 그립니다.

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)
edge = cv2.Canny(blur, 50, 150)

contours, _ = cv2.findContours(
    thresh,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

result = img.copy()
for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < 2500:
        continue
    x, y, w, h = cv2.boundingRect(cnt)
    cv2.rectangle(result, (x, y), (x + w, y + h), (0, 0, 255), 2)

작은 노이즈까지 박스로 잡히면 cv2.contourArea로 작은 영역을 제외합니다.

5. HSV 색상 마스크

RGB/BGR보다 HSV는 특정 색을 찾기 편합니다. 빨간색 공, 빨간 문처럼 색 기준으로 객체를 찾을 때 사용합니다.

hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

lower_red1 = np.array([0, 100, 100])
upper_red1 = np.array([10, 255, 255])
lower_red2 = np.array([170, 100, 100])
upper_red2 = np.array([179, 255, 255])

mask1 = cv2.inRange(hsv, lower_red1, upper_red1)
mask2 = cv2.inRange(hsv, lower_red2, upper_red2)
mask = cv2.bitwise_or(mask1, mask2)

result = cv2.bitwise_and(img, img, mask=mask)

빨간색은 HSV에서 0 근처와 179 근처로 나뉘기 때문에 범위를 두 개 잡는 경우가 많습니다.

6. 영상 처리와 움직임 감지

영상은 이미지 프레임이 빠르게 이어진 것입니다. VideoCapture로 프레임을 하나씩 읽고 처리합니다.

cap = cv2.VideoCapture("opencv/videos/video3.mp4")
prev_frame = None

while True:
    ret, frame = cap.read()
    if not ret:
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    if prev_frame is None:
        prev_frame = gray
        continue

    diff = cv2.absdiff(prev_frame, gray)
    _, thresh = cv2.threshold(diff, 80, 255, cv2.THRESH_BINARY)
    thresh = cv2.dilate(thresh, None, iterations=2)

    prev_frame = gray

cap.release()
cv2.destroyAllWindows()

움직임 감지는 “이전 프레임과 현재 프레임의 차이”를 이용합니다.
