NumPy 배열 계산 정리

NumPy는 숫자 데이터를 빠르게 다루기 위한 라이브러리입니다. 이 폴더에서는 배열 생성, 인덱싱, 슬라이싱, reshape, 조건 검색, 브로드캐스팅을 중심으로 배웠습니다.

1. NumPy를 왜 쓰는가

파이썬 리스트는 값을 순서대로 담는 데 좋지만, 숫자 계산을 한 번에 처리하기에는 불편합니다. NumPy 배열은 같은 모양의 데이터에 연산을 한 번에 적용할 수 있습니다.

import numpy as np

list_result = [1, 2, 3] + [4, 5, 6]
array_result = np.array([1, 2, 3]) + np.array([4, 5, 6])

print(list_result)   # [1, 2, 3, 4, 5, 6]
print(array_result)  # [5 7 9]

핵심은 “리스트의 +는 이어붙이기, NumPy 배열의 +는 같은 위치끼리 계산”입니다.

2. 배열의 기본 정보

속성/함수의미예시
arr.shape배열의 모양(3, 4)는 3행 4열
arr.ndim차원 수1차원, 2차원, 3차원
arr.size전체 데이터 개수3행 4열이면 12개
arr.dtype데이터 타입int64, float64, uint8
 
scores = np.array([
    [98, 89, 78],
    [94, 74, 56],
    [75, 68, 81]
])

print(scores.shape)  # (3, 3)
print(scores.ndim)   # 2
print(scores.size)   # 9
print(scores.mean()) # 전체 평균

3. 인덱싱과 슬라이싱

배열에서 원하는 위치만 가져오는 방법입니다. 이미지 처리와 데이터 분석에서 아주 자주 씁니다.

arr = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
])

print(arr[0])       # 첫 번째 행
print(arr[:, 1])    # 모든 행의 두 번째 열
print(arr[0:2, 1:3])# 0~1행, 1~2열

형식은 arr[행, 열]입니다. :는 “전체” 또는 “범위”라는 뜻으로 읽으면 됩니다.

4. reshape와 자동 배열 생성

np.arange로 연속 숫자를 만들고 reshape로 모양을 바꿉니다. 단, 전체 데이터 개수는 맞아야 합니다.

arr = np.arange(1, 16)
arr2 = arr.reshape(3, 5)
arr3 = arr.reshape(5, -1)

print(arr2)
print(arr3)

주의: 15개 데이터를 (4, 4)로 바꾸면 16칸이 필요하므로 에러가 납니다. -1은 NumPy가 자동 계산한다는 뜻입니다.

5. 조건 검색과 boolean indexing

조건에 맞는 값만 뽑을 때 사용합니다. 성적에서 80점 이상, 이미지에서 밝기 200 이상 같은 문제에 바로 연결됩니다.

score = np.array([88, 94, 53, 67, 72])

print(score >= 80)
print(score[score >= 80])
print(score[score % 2 == 0])
img = np.array([
    [10, 20, 30, 40, 50],
    [60, 200, 210, 70, 80],
    [90, 220, 255, 100, 110]
])

bright = img >= 200
copy_img = img.copy()
copy_img[bright] = 255

6. 브로드캐스팅

모양이 완전히 같지 않아도 계산 가능한 규칙이면 작은 배열을 자동으로 맞춰 계산합니다.

img = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

v = np.array([10, 20, 30])
print(img + v)

v2 = np.array([[100], [200]])
print(img + v2)

이미지에서 RGB 채널마다 값을 더하거나, 행마다 다른 값을 더할 때 이런 감각이 필요합니다.
