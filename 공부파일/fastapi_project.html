학생 성적·출석 분석 API 프로젝트

이 프로젝트는 FastAPI로 API를 만들고, SQLAlchemy로 DB를 다루며, Pandas와 Matplotlib으로 학생 성적과 출석 데이터를 분석해 그래프와 PDF 보고서까지 만드는 흐름입니다.

1. 전체 구조

프로젝트는 역할별로 폴더가 나뉩니다. 이 구조를 이해하면 코드가 어디에 들어가야 하는지 판단하기 쉬워집니다.

폴더/파일역할

2. FastAPI 앱 시작점

main.py는 서버의 입구입니다. 앱을 만들고, DB 테이블을 생성하고, 라우터를 연결합니다.

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()
Base.metadata.create_all(bind=engine)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(student_router.router)
app.include_router(score_router.router)
app.include_router(attend_router.router)
app.include_router(analysis_router.router)

라우터를 분리하면 기능이 많아져도 main.py가 복잡해지지 않습니다.

3. 모델: DB 테이블 설계

모델은 데이터베이스 테이블의 모양입니다. 학생, 성적, 출석 테이블이 있고 성적/출석은 학생 id를 참조합니다.

class Student(Base):
    __tablename__ = "student"

    id = Column(Integer, primary_key=True, index=True)
    name = Column(String(50), nullable=False)
    class_n = Column(String(100), nullable=False)
    team = Column(String(100), nullable=False)
class Score(Base):
    __tablename__ = "score"

    id = Column(Integer, primary_key=True, index=True)
    student_id = Column(Integer, ForeignKey("student.id"))
    python_score = Column(Integer)
    numpy_score = Column(Integer)
    pandas_score = Column(Integer)
    java_score = Column(Integer)
    project_score = Column(Integer)

성적과 출석은 반드시 어떤 학생의 데이터인지 알아야 하므로 student_id가 중요합니다.

4. Router와 Service 분리

Router는 요청을 받고, Service는 실제 작업을 합니다. 이렇게 나누면 URL 처리와 계산 로직이 섞이지 않습니다.

@router.post("/scores")
def create_score(score: ScoreCreate, db: Session = Depends(get_db)):
    return create_score_service(db, score)

@router.get("/scores")
def get_scores(db: Session = Depends(get_db)):
    return get_score_list(db)
def create_score_service(db, score):
    score_data = [
        score.python_score,
        score.numpy_score,
        score.pandas_score,
        score.java_score,
        score.project_score,
    ]

    for value in score_data:
        if value < 0 or value > 100:
            raise HTTPException(status_code=404, detail="점수 범위 오류")

검증, 계산, DB 저장 같은 실제 처리는 service 쪽에 두면 유지보수가 쉽습니다.

6. 분석 기능

분석 서비스는 DB에서 성적과 출석 데이터를 가져와 평균, 최댓값, 최솟값, 표준편차, 관리 대상 학생, 우수 학생을 계산합니다.

avg = (
    score.python_score
    + score.numpy_score
    + score.pandas_score
    + score.java_score
    + score.project_score
) / 5

total_count = (
    attend.attend
    + attend.late
    + attend.absent
    + attend.early_leave
)

rate = (attend.attend / total_count) * 100
  • 평균 점수가 낮거나 출석률이 낮으면 관리 대상 학생으로 분류합니다.
  • 평균 점수와 출석률이 모두 높으면 우수 학생으로 분류합니다.
  • Matplotlib으로 성적 분포 그래프와 출석률 그래프를 생성합니다.
  • ReportLab으로 PDF 보고서를 생성합니다.
