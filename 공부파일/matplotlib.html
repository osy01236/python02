Matplotlib 시각화 정리

Matplotlib은 숫자와 표 분석 결과를 사람이 보기 쉬운 그래프로 바꿔줍니다. 이 폴더에서는 선 그래프, 막대 그래프, 이미지 표시, bounding box, 그래프 저장을 연습했습니다.

1. 기본 그래프 구조

그래프는 보통 x값, y값, 제목, 축 이름, 눈금, 출력 순서로 작성합니다.

import matplotlib.pyplot as plt

x = ["python", "numpy", "pandas", "opencv"]
y = [80, 75, 90, 70]

plt.plot(x, y)
plt.title("Study Score")
plt.xlabel("subject")
plt.ylabel("score")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

한글 제목을 쓰려면 폰트 설정이 필요합니다. Windows에서는 보통 Malgun Gothic을 사용합니다.

plt.rcParams["font.family"] = "Malgun Gothic"
plt.rcParams["axes.unicode_minus"] = False

2. figure, subplot, 저장

figure는 그림판 크기를 정하고, subplot은 한 화면에 여러 그래프를 배치합니다.

plt.figure(figsize=(8, 4))

plt.subplot(1, 2, 1)
plt.imshow(copy_img, cmap="gray")
plt.title("copy")
plt.axis("off")

plt.subplot(1, 2, 2)
plt.imshow(img, cmap="gray")
plt.title("original")
plt.axis("off")

plt.savefig("test.png", dpi=300, transparent=True)
plt.show()
옵션의미
figsize그래프 크기
dpi저장 해상도
transparent배경 투명 여부
tight_layout겹치는 여백 자동 정리

3. 이미지 표시와 흑백 처리

이미지도 배열입니다. NumPy로 만든 배열이나 이미지 파일을 imshow로 표시할 수 있습니다.

import numpy as np
import matplotlib.pyplot as plt

img = np.random.randint(0, 256, (100, 100))

copy_img = img.copy()
copy_img[copy_img >= 128] = 255
copy_img[copy_img < 128] = 0

plt.imshow(copy_img, cmap="gray")
plt.axis("off")
plt.show()

흑백 이미지는 cmap="gray"를 지정해야 사람이 기대하는 색으로 보입니다.

4. JSON 좌표로 bounding box 그리기

AI 데이터셋의 annotation에는 물체 위치가 좌표로 들어 있습니다. 이 좌표를 읽어 이미지 위에 사각형으로 표시했습니다.

import json
import matplotlib.pyplot as plt
import matplotlib.patches as patches

with open("18396603_frame_20.json", "r", encoding="utf-8") as f:
    data = json.load(f)

img = plt.imread("18396603_frame_20.png")
plt.imshow(img)
ax = plt.gca()

box = patches.Rectangle(
    (x, y),
    width,
    height,
    fill=False,
    edgecolor="red",
    linewidth=2
)

ax.add_patch(box)
plt.show()

이미지 좌표는 왼쪽 위가 시작점입니다. x는 오른쪽으로, y는 아래쪽으로 증가합니다.

5. 객체 개수 그래프

JSON에서 car, truck, person 개수를 세고 막대 그래프로 표현하는 흐름입니다.

counts = {"car": 0, "truck": 0, "person": 0}

for ann in data["frames"]["annotations"]:
    code = ann["category"]["code"]
    if code == "vehicle":
        value = ann["category"]["attributes"][0]["value"]
        counts[value] += 1
    elif code == "person":
        counts["person"] += 1

labels = list(counts.keys())
values = list(counts.values())

plt.bar(labels, values, color=["blue", "red", "green"])
plt.ylim(0, max(values) + 1)
plt.show()
